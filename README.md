# NEURAL.DRAW — AI Hand Gesture Interface ✋🎨

> Real-time AI hand gesture air drawing, 3D holographic shape visualization, and gesture-controlled cyber music player powered by MediaPipe and Three.js.

🔗 **Live Demo:** [https://akhil-tech258.github.io/Hand/](https://akhil-tech258.github.io/Hand/)

---

## 🌟 Features

- ☝️ **Air Drawing System**: Draw in mid-air using index-finger hand tracking detected directly through your browser webcam via MediaPipe Hands.
- 🧹 **Dynamic Modes**: Seamlessly switch between Draw, Erase, 3D Shape manipulation, and Pan modes using hand gestures or on-screen controls.
- 🌐 **3D Holographic Rendering**: Interactive Three.js WebGL renderer displaying 3D shapes (Cube, Sphere, Pyramid, Torus) that respond to spatial hand movements.
- 🎵 **Gesture Music Player**: Built-in cyberpunk audio player with responsive live equalizer bars, controllable via hand gestures (Play, Pause, Next, Prev, Volume).
- 📤 **Digital Drawing Sheet & Export**: One-click drawing transfer with high-resolution PNG export functionality.
- 📱 **Fully Responsive UI**: Mobile-optimized cyberpunk interface with fluid grid layouts, touch controls, and adaptive viewports.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Cyberpunk / Glassmorphism UI), Vanilla JavaScript (ES6+)
- **Computer Vision**: [MediaPipe Hands](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker) (Real-time 21 3D hand landmarks)
- **3D Graphics**: [Three.js](https://threejs.org/) (WebGL rendering, custom meshes, lighting & materials)
- **Audio**: Web Audio API & Synth Audio Engine

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Akhil-tech258/Hand.git
   ```
2. Open `index.html` in any modern web browser with webcam access (Chrome, Edge, Firefox, Safari).
3. Click **"▶ ACTIVATE WEBCAM"** and grant camera permissions to begin air drawing!
